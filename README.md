# Real Estate Market Trends

## Project Overview
This project analyzes real estate data to identify property price patterns, location-based trends, and relationships between property area and price.

## Objectives
- Analyze property prices across different locations
- Compare apartment and villa prices
- Study the relationship between property area and price
- Calculate statistical measures such as mean, median, minimum, and maximum
- Present insights using data visualizations

## Technologies Used
- Python
- Pandas
- Matplotlib
- Streamlit
- Statistical Analysis
- Git & GitHub

## Key Skills Demonstrated
- Data analysis
- Data cleaning and preparation
- Statistical analysis
- Data visualization
- Dashboard development
- GitHub version control

## Dashboard Features
- Property dataset overview
- Average price by location
- Area vs. price visualization
- Property type analysis
- Statistical summary
- Key market insights
